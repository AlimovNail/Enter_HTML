Моя первая веб-страница

HTML (HyperText Markup Language) — это язык гипертекстовой разметки, который используется для создания структуры веб-страниц. С его помощью можно размещать на странице текст, изображения, ссылки, таблицы и другие элементы.

HTML не является языком программирования, поскольку не содержит логики выполнения алгоритмов.
Он использует специальные теги для разметки содержимого веб-страницы и обычно применяется совместно с CSS для оформления и JavaScript для добавления интерактивности.
