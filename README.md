# Enter_HTML
Практические задания по предмету "Введение в HTML"
Цель задания: освоить базовые принципы создания веб-страниц, включая работу с основными элементами HTML, построение структуры документа, добавление мультимедийного контента, создание форм и применение семантической разметки.

Задача 1 – Создание базовой HTML-страницы
1) Создайте новый файл с расширением .html в текстовом редакторе;
2) Реализуйте базовую структуру HTML-документа, включив обязательные элементы: <!DOCTYPE html>, <html lang="ru">, <head> (с указанием кодировки UTF-8 и настройками адаптивности для мобильных устройств), <title> и <body>.
3) В теле документа разместите:
•	Заголовок 1-го уровня с текстом «Моя первая веб-страница»;
•	Два абзаца текста: в 1-ом опишите назначение HTML, во 2-ом — его отличия от языков программирования.
4) Примените базовое форматирование текста:
•	Выделите один из абзацев с помощью тега <strong>;
•	Один фрагмент текста выделите курсивом с помощью тега <em>;
•	В одном из абзацев используйте тег <br> для переноса строки;
5) Сохраните файл и откройте его в браузере для проверки корректности отображения.

Задача 2 – Разработка персональной веб-страницы
Создайте HTML-страницу «Моя персональная веб-страница», используя базовые элементы разметки:
1) Структура и заголовки: используйте иерархию заголовков: <h1> для названия страницы, <h2> и <h3> — для разделов («О себе», «Мои увлечения», «Контакты» и т.д.);
2) Текстовое содержимое: добавьте несколько абзацев текста, раскрывающих содержание разделов;
3) Списки: создайте маркированный список («Мои увлечения») и нумерованный список («Мои любимые книги»);
4) Мультимедиа: добавьте изображение, используя относительный путь к файлу;
5) Гиперссылки: вставьте абсолютную гиперссылку на внешний ресурс и якорную ссылку для навигации внутри страницы;
6) Таблица: создайте таблицу для представления структурированных данных (расписание дня или список навыков);
7) Видео или аудио: встройте на страницу видео- или аудиофайл;
8) Сохраните файл под именем и проверьте его отображение в браузере

Задача 3 – Создание формы обратной связи
Разработайте HTML-форму для сбора обратной связи, содержащую следующие элементы:
1) Текстовое поле для имени пользователя (обязательное для заполнения);
2) Поле для ввода адреса электронной почты с валидацией формата;
3) Группу переключателей для выбора пола (с возможностью выбора только одного варианта);
4) Флажок для подтверждения согласия с условиями (обязательный для отмечания);
5) Раскрывающийся список для выбора страны проживания (не менее 3 вариантов);
6) Кнопку отправки формы.
Убедитесь в корректной работе атрибутов валидации (required, type="email", правильное использование атрибута name для группы переключателей). Форма должна быть логично подписана и структурирована.

Задание 4 – Применение семантической разметки
Создайте веб-страницу, демонстрирующую использование семантических тегов HTML5.
1) Реализуйте структуру страницы, включающую:
•	Верхний колонтитул (<header>) с логотипом и названием сайта;
•	Навигационное меню (<nav>) со списком ссылок;
•	Основной контент (<main>), содержащий несколько тематических разделов (<section>);
•	Нижний колонтитул (<footer>) с контактной информацией.
2) Пример наполнения:
•	В <header> разместите логотип и заголовок;
•	В <nav> добавьте минимум три пункта меню (ссылки-заглушки);
•	В <main> создайте два раздела (<section>) с уникальными заголовками и текстовым содержимым;
•	В <footer> укажите контактные данные.
