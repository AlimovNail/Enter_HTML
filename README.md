Практическое задание по дисциплине «Основы CSS»

Цель задания: закрепить на практике базовые навыки верстки веб-страницы по готовому макету, включая работу с Flexbox, позиционированием, оформлением фона, форм и применением CSS-свойств для стилизации элементов.

Важно: задание выполняется строго в соответствии с предоставленным видео-уроком. Необходимо повторять все действия преподавателя, чтобы добиться идентичного результата.

Примечание: при невозможности использовать идентичные изображения из видео (фон, иконки), допускается применение любых других изображений-заглушек аналогичного назначения и размера для отработки технических приемов верстки.

Задача – Верстка страницы авторизации
Необходимо сверстать страницу с формой авторизации, максимально приближенную к макету из видео.
Этапы работы:
1) Подготовка рабочей среды;
2) Базовая разметка HTML;
3) Стилизация с помощью CSS;
4) Проверка результата
